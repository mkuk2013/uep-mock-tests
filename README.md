# UEP Mock Tests

**United Energy Pakistan (UEP) — NTS Pattern Practice Tests**

Online mock-test PWA for UEP written-test preparation (Field Production Trainee and similar roles), following the NTS-style paper pattern.

## What's inside

- 10 mock tests, **100 MCQs per test** (1,000 questions total), **90-minute timer** with auto-submit
- Section pattern per test (100 marks):
  - English — 30 (grammar, vocabulary, sentence completion, reading comprehension, analogies)
  - Physics & Everyday Science — 30 (SI units, heat, motion, electricity, general science)
  - Chemistry — 15 (chemical formulas, states of matter, basic concepts)
  - Basic Mathematics — 15 (averages, percentages, ratios, proportions, word problems, arithmetic)
  - General Knowledge, Pak Studies, Current Affairs & Islamic Studies — 10
- All tests are **password protected** — students contact on WhatsApp to get the password
- Name entry, question palette, instant results with section-wise breakdown and full answer review
- Installable as a PWA (Install App button on the page)

## Run / Deploy

Static site — no build step. Netlify publishes the repository root (`publish = "."` in `netlify.toml`).
